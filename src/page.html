Marlow Tower

MARLOW INTERNATIONAL · EGMW · DELIVERY / GROUND / TOWER

You are the controller on duty. Aircraft call in with real radiotelephony, you answer with the same phrases. Get it wrong and runways get crowded, read-backs go unchecked and aircraft meet in the wrong place.

  • Select an aircraft, then press Accept, Deny or Wait to send the standard reply, or type / speak your own.
  • Listen to every read-back. A wrong digit or a missing “hold short” has to be caught.
  • Keep the runway clear before clearing anyone to land or take off.
  • The Manual (key M) has every phrase, searchable.

Gemini voices need network access to Google, so use the downloaded HTML file in Chrome or Edge. Microphone input uses your browser's speech recognition; typing always works.
